一、实验目的

  1. 掌握 HTML5 Canvas 2D 绘图基础，理解画布坐标系，熟悉像素坐标、矩形、线段、圆弧、图像、文字等基础绘图 API 的使用方法。
  2. 学会使用`save()`与`restore()`保存和恢复绘图状态，理解绘图状态与已经绘制像素的区别。
  3. 掌握绘图顺序、图层覆盖原理，能够将背景、装饰图形、图片、文字组合绘制在同一张画布，完成黄梅戏宣传卡综合绘制。
  4. 区分**画布内部像素尺寸**与 CSS 页面显示尺寸的概念，学会调试 Canvas 绘图代码，理解路径`beginPath()`的作用，避免图形多余连接。

二、实验环境与工具

操作系统：Windows
开发编辑器：Visual Studio Code
浏览器：Microsoft Edge
技术：HTML5、CSS、JavaScript（Canvas 2D API）
项目文件：index.html、drawing.js、runner.js、assets 素材图片

三、实验内容

  • T1:背景铺满画布，边框四周留20像素；改变背景色后重新运行能看到变化。
  • T2:线条与圆不出现多余连接；能说明圆心、半径和角度参数。
  • T3:三个矩形依次深枣红、柔金、深枣红，前两个不会消失；能说明restore恢复状态而非撤销图形。
  • T4:标题、说明和图片同时可见，文字不被背景覆盖。单项通过后，再点击“绘制完整宣传卡”检查组合效果。
  • T5:完整卡片包含背景、线、圆、三色状态示例、图像与文字；缩小显示后canvas.width/height仍为600/360。恢复显示；所有阶段均可重新运行。

四、实验步骤

  • T1：编写drawBackground函数，设置填充色#FFF5E8，用fillRect绘制600×360画布背景；设置描边颜色#702B32、线宽2，用strokeRect绘制(20,20,560,320)的外边框。单独运行T1，验证背景铺满画布，边框四周预留20px空白。
  • T2：编写drawDecoration函数，调用beginPath开启独立路径，绘制从(30,280)到(570,280)的水平分隔线；再次beginPath新建路径，使用arc绘制圆心(500,85)、半径35的柔金色实心圆。单独运行T2，检查线条与圆形无多余连接。
  • T3：编写drawState函数，绘制第一个深枣红色矩形；调用save保存绘图状态，修改颜色绘制柔金色矩形；调用restore恢复状态，绘制第三个矩形。单独运行T3，观察三个矩形颜色依次为深枣红、柔金、深枣红。
  • T4：编写drawContent函数，使用drawImage在(30,70)绘制宽270高180的黄梅戏人物图片；设置字体与暖墨色，用fillText依次绘制标题“黄梅雅韵”、副标题“听乡音·赏戏韵”、说明文字“校园戏曲体验日”。单独运行T4，确认图片与文字正常显示。
  • T5：组合验证，点击绘制完整宣传卡，一次性渲染全部元素；修改一处颜色、一处坐标，观察画面变化；切换画布显示尺寸，区分画布像素尺寸和CSS显示尺寸，记录现象并截图。

五、结果与分析

R1 单项检查

T1背景边框:背景带黄色，边框砖红色、T2路径：右上角黄色圆形装饰和下方一条黄色分割线、T3三色顺序砖红色，金色，砖红色三个矩形色块、T4a图片位置：画面左侧一张绘图，上方“黄梅雅韵”四个字，T4b文字效果，分别记录实际结果：正常显示，无遮挡。

R2 对比与解释

将 T2 圆形装饰颜色由柔金色 #D9B66F 修改为深枣红 #702B32，圆形颜色随之改变，同时将图片 x 坐标由 30 改为 60，图片整体向右平移；切换缩小显示后 canvas.width/height 仍然为 600 和 360，仅 CSS 改变页面显示大小，画布内部像素尺寸不变；restore 不会擦除已经绘制的图形，它只恢复颜色、线宽这类绘图状态属性，已经绘制完成的像素画面不会被撤销清除。
