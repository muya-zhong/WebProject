2. 空白与换行对照

修改前的预测
预测 <p> 标签会合并连续空格，源码换行不产生页面换行；<pre> 标签保留源码内所有连续空格与换行。
实际观察与分析
观察结果：<p> 将源码多个连续空白、回车压缩为单个空格，不会保留源码换行；<pre> 原样展示源码空格与换行。原因：<p> 是普通段落，浏览器自动折叠空白；<pre> 预格式化标签保留源码排版。实验完成后恢复原标签。

3. 有序列表编号

初始编号预测与实测
start="3"，代表有序列表从数字3开始计数；第二项设置value="7"，则第二项编号强制为7，后续项在7基础上递增。预测：3、7、8、9；实测结果与预测一致。
修改后的编号与分析
仅将value改为5后，四项编号：3、5、6、7。原因：start设置列表起始值，value单独强制修改当前li的编号，后面元素自动顺延。实验后恢复标签。选做type="A"时，会使用大写英文字母编号。

4. 两处列表错误的修复

错误一


      <ul>
        <li>《天仙配》欣赏要点</li>
        <ul>
          <li>人物关系</li>
        </ul>
      </ul>
    

      <ul>
        <li>《天仙配》欣赏要点
          <ul>
            <li>人物关系</li>
          </ul>
        </li>
      </ul>

修复理由：HTML规定<ul>的直接子元素只能是<li>。原代码将子<ul>直接放在外层<ul>下，属于非法嵌套；修改后把子列表移入<li>标签内部，符合列表嵌套语法规范。

错误二


      <dl>
        <dt>唱腔<dd>戏曲演唱的曲调表达</dd></dt>
      </dl>
    

      <dl>
        <dt>唱腔</dt>
        <dd>戏曲演唱的曲调表达</dd>
      </dl>

修复理由：<dt>与<dd>是同级兄弟标签，不能互相嵌套。原代码将<dd>写在<dt>标签内部，HTML结构非法；修改后把<dt>和<dd>改为同级节点，符合定义列表<dl>的语法规范。
