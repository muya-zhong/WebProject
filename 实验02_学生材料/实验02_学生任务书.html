实验二 黄梅戏介绍页

Web前端技术实验 · 2026—2027学年第一学期
建议2学时，共90分钟 · 独立完成

本次使用HTML制作图文并茂的黄梅戏介绍页。读者应能了解黄梅戏概况、代表剧目和戏曲术语，看到相关图片，并通过链接查阅资料。

本任务书本身就是本节课的HTML示例。可用VS Code打开本文件，对照浏览器查看标题、段落、三类列表、图片、链接和代码片段的写法。先理解内容含义，再选择标签。

一 学习目标

  • 使用<h1>、<h2>、<p>组织标题和段落，区分<br>换行与段落分隔。
  • 使用<strong>、<em>、<sup>、<sub>表达重要性、强调和上下标。
  • 使用<ul>、<ol>、<dl>表达并列事项、先后步骤及名称与说明。
  • 使用<pre>与<code>显示带缩进的源码，理解字符转义。
  • 插入本地图片，填写alt并保留图片来源；实现外部链接与页内跳转。

准备：会用VS Code打开文件夹、编辑保存，并用浏览器打开和刷新HTML。复制“起始项目”，按“实验02-专业-年级-班级-姓名-学号”命名，例如“实验02-大数据-24级-1班-张三-学号”。

二 素材与图片

先打开黄梅戏素材库，从12段文字和4张本地图片中选取需要的内容。无需重新下载图片；起始项目的images目录已经备齐文件。

  • 页面素材：页面内容与编写提示。
  • 可选文字素材：概况、特点、代表剧目、校园实践和欣赏建议。
  • 超链接清单：9个文化资料或图片来源链接。
  • 图片作者与许可说明：选用图片时保留对应署名。
  • 图片与链接代码片段：可对照修改路径和说明。

文化概况可查阅中国非物质文化遗产网的黄梅戏介绍[1]。外部资料需联网，本地正文与图片可离线阅读。

“入门欣赏步骤”提供一种了解黄梅戏的方法，同学们也可以根据自己的经验调整顺序。

三 任务要求

标题与概况
一个<h1>，至少四个<h2>；撰写两段介绍，每段至少40个汉字。
文本语义
重要提醒用<strong>，语气强调用<em>；资料来源与整理者用一次<br>分行；用<hr>表示主题转换。资料注号使用<sup>，记录编号变量x1使用<sub>，并注明它只是下标练习。
三类列表
<ul>列出至少3个剧目，其中一个li内嵌套至少2项欣赏要点；<ol>列出至少4个入门步骤；<dl>至少3组<dt>与<dd>，解释唱腔、念白、身段。
代码摘录
用<pre>和<code>显示至少3行带缩进的HTML，尖括号通过字符引用显示。
图片
至少1张相关图片，放在项目images目录，以相对路径引用。alt要有实际含义；图注注明作者、来源和许可。保持图片比例。
超链接
至少1个外部文化资料链接和1个页内锚点链接。链接文字清楚，目标id唯一，点击后能跳到对应位置。

styles.css提供基础排版，可直接使用。任务书附录使用表格方便查阅，本实验不要求学生制作表格，也不要求JavaScript或表单。

四 对照实验与纠错

空白与换行

打开checks.html，先预测<p>与<pre>中的连续空格和换行如何显示，再观察。仅将<p>改成<pre>，记录变化后恢复原标签。不要改动实验文本中的空白。

有序列表编号

<ol>设置start="3"，第二项li设置value="7"。先预测四项编号，再观察；仅将value改为5后再次观察，最后恢复7。选做：将<ol>的type改为A。

列表结构纠错

debug.html包含两处故意设置的错误：子列表位置错误、<dd>写进<dt>。各记录修改前后代码与理由。浏览器能显示不代表源代码结构正确。

图片和链接验证

  • 从本地打开index.html，确认图片加载、比例正常、alt和署名已填写。
  • 点击外部资料链接，核对目标页面；若网络不可用，如实记录未完成联网验证。
  • 点击页内导航，确认跳至对应栏目；目标id不得重复。

附录 标签与英文名称

英文列区分缩写、完整单词和记忆名称。正文用HTML语义组织，CSS只负责基础显示。

本节课标签速查
标签 英文全称或名称 含义与使用注意 简短示例
<html> HyperText Markup Language
超文本标记语言（缩写）		 HTML文档的根元素；lang声明页面主要语言。 <html lang="zh-CN">…</html>
<head> head
头部（完整单词）		 存放标题、编码、样式引用等元信息。 <head>…</head>
<meta> metadata
元数据（缩略形式）		 声明元信息；本实验设置UTF-8编码和视口。空元素，无结束标签。 <meta charset="utf-8">
<title> title
标题（完整单词）		 浏览器标签页中的文档标题，不是正文标题。 <title>黄梅戏介绍</title>
<link> link
链接（完整单词）		 引用外部资源；本实验连接CSS文件。空元素。 <link rel="stylesheet" href="styles.css">
<body> body
主体（完整单词）		 包含网页向读者呈现的主要内容。 <body>…</body>
<h1>—<h6> heading 1–6
第1至第6级标题		 六级标题，数字越大层级越低。按内容层级选用，不按字号选用。 <h1>走近黄梅戏</h1>
<h2>代表剧目</h2>

<br> line break
换行（记忆释义）		 同一文本块中有意义的换行；不用于制造段落间距。空元素。 资料来源：非遗网<br>整理者：张明
<hr> horizontal rule
水平分隔线（传统名称）		 段落级主题转换，通常显示为分隔线。空元素。 <p>概况</p><hr><p>详细介绍</p>
<strong> strong
强烈的（完整单词）		 表示重要、严肃或紧迫的内容，通常以粗体显示。 <strong>请核对资料来源。</strong>
<em> emphasis
强调（缩写）		 表示语气强调，通常以斜体显示。 <em>先理解情境</em>
<sup> / <sub> superscript / subscript
上标 / 下标（缩写）		 <sup>表示上标，<sub>表示下标；用于确实需要上下标的内容。 资料<sup>[1]</sup>

无序列表（缩写）		 无序列表：用于没有固定先后顺序的并列事项。 <ul><li>《天仙配》</li></ul>
<ol> ordered list
有序列表（缩写）		 有序列表：用于有先后顺序的步骤或排名。 <ol><li>查阅资料</li></ol>

列表项（缩写）		 列表项，放在<ul>或<ol>内；子列表应放在所属li内。 <li>剧目<ul><li>欣赏要点</li></ul></li>
<dl> description list
描述列表；旧称definition list		 描述列表，表达名称与说明之间的关联。 <dl><dt>唱腔</dt><dd>演唱的曲调表达</dd></dl>

描述项名称（记忆释义）		 描述列表中的名称或术语；本实验直接放在<dl>内。 <dt>念白</dt>

描述详情（记忆释义）		 对应术语的说明；本实验与<dt>并列，不能写进<dt>。 <dd>戏曲人物的说白。</dd>

<code> code
代码（完整单词）		 表示一段计算机代码；多行源码通常与<pre>配合。 <pre><code>&lt;p&gt;介绍&lt;/p&gt;</code></pre>
<a> anchor
锚（缩写）		 超链接，href指定目标网页或本地文件。 <a href="checks.html">验证页</a>

粗体 / 斜体（传统名称）		 <b>吸引注意但不增加重要性；<i>表示不同语态，如术语或异语。不能只按粗体、斜体外观选标签。 <b>关键词</b>

删除 / 插入的文本		 表示删除、插入的内容；适用于记录文字修订，属选做。 <del>旧介绍</del><ins>新介绍</ins>

<figure> figure 图或独立内容 将图片与说明组合为独立内容。 <figure>图片及图注</figure>
<figcaption> figure caption 图注 在<figure>内说明图片及其来源。 <figcaption>作者及来源</figcaption>

属性与字符引用

src — source
图片来源地址。示例：src="images/huangmei-stage.jpg"。
alt — alternative text
替代文本，简洁说明图片表达的内容。
href — hypertext reference
链接目标，可以是外部地址、本地文件或#栏目id。
id — identifier
元素标识，同一页面中必须唯一。
start / value / type
有序列表的起始序数、列表项序数和编号形式，均为属性。

<!doctype html>是文档类型声明。&lt;显示“<”，&gt;显示“>”，&amp;显示“&”；这些是字符引用，不是标签。

不使用<font>、<center>或align等旧式表现写法；字体、颜色和对齐交给CSS。
