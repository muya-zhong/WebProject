  4. 巩固 HTML 结构与 CSS 样式分离的开发思想，学会在指定代码区域内完成网页开发，不擅自修改原有 CSS 与 JS 脚本。

五、结果与分析

R1 关键实现

使用 fieldset+legend 实现表单分组；label 通过 for 绑定 id 实现点击文字选中；select 下拉选择剧目；number 输入框搭配 min、max、step、required 属性，限制票价范围并设为必填项。 


      <fieldset>
          <legend>演出筛选条件</legend>
          <label for="play">剧目</label>
          <select id="play" name="play">
            <option value="all">全部剧目</option>
            <option value="tianxianpei">天仙配</option>
            <option value="nvfuma">女驸马</option>
          </select>
          <label for="budget">最高票价</label>
          <input id="budget" type="number" name="budget" value="200" min="0" max="500" step="10" required/>
      </fieldset>
